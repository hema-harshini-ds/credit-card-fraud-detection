Credit Card Fraud Detection Dashboard

📊 Project Overview

An interactive Tableau dashboard created to analyze credit card transaction data and identify fraud patterns.

🛠️ Tools Used

- Tableau
- Data Visualization
- Data Analysis

📈 Dashboard Features

- Transaction amount analysis
- Fraud percentage visualization
- Transaction trends over time
- Interactive filters
- Visual analysis of fraud patterns
